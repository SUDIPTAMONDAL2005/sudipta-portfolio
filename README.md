# Sudipta Mondal — Portfolio

Personal portfolio: static HTML, CSS and JavaScript with a Three.js 3D background. No build step.

## Publish on GitHub Pages
1. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (or any name).
2. Upload all files in this folder (keep `index.html` at the top level).
3. Repository **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`.
4. Your site goes live at `https://YOUR-GITHUB-USERNAME.github.io/` within a minute or two.

Before publishing, replace `YOUR-GITHUB-USERNAME` in the GitHub button in `index.html`.
